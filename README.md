# Milton 麋爾頓美語官方網站

這是一個使用 Vite + React 建立的單頁式網站，包含首頁、Prime 基礎英語、ESL 主題探索、課後照顧與聯絡資訊。

## 目前內容

- 首頁 Hero 與 3D 吉祥物視覺
- Milton 教育理念與學習路線
- Prime / ESL 課程分頁
- 課後照顧介紹
- 單字複習任務連結
- LINE、電話與校區地圖資訊
- RWD 響應式版面

## 常用指令

```bash
npm install
npm run dev
npm run build
```

## 可調整連結

主要設定在 `src/main.jsx`：

- `REVIEW_APP_URL`：單字複習任務網址
- `LINE_URL`：LINE 官方帳號連結
