# Milton 官方形象網站 v1

這是 Milton 麋爾頓美語官方形象網站第一版。

## 目前包含
- 首頁主視覺
- 關於 Milton
- 課程介紹
- 教學特色
- 學生作業系統入口
- 聯絡我們
- 手機版 RWD

## 之後需要替換
在 `src/main.jsx` 內：
- `REVIEW_APP_URL`：目前接到 https://milton-vocab-app.vercel.app/
- `LINE_URL`：目前是 #，之後可換成 LINE 官方帳號連結
- 電話與地址文案
